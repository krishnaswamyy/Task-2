Tools & Technologies

---

 Task Objective
The objective of this task is to clean a dataset by identifying and handling missing values.
This task focuses on improving data quality to make the dataset suitable for machine learning models.

---

 Steps Performed
1. Loaded the dataset into Google Colab using Pandas  
2. Identified missing values using `.isnull().sum()`  
3. Visualized missing value distribution using bar charts  
4. Applied median imputation for numerical columns  
5. Applied mode imputation for categorical columns  
6. Removed columns with extremely high missing values (if any)  
7. Validated the dataset after cleaning  
8. Saved the cleaned dataset as a CSV file  

---

 Missing Value Handling Techniques
- **Numerical columns:** Median imputation  
- **Categorical columns:** Mode imputation
